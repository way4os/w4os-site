# Pour commencer

1. **Créez votre avatar** sur la [page d'inscription](/fr/register) : choisissez son nom, sa première tenue et un mot de passe, puis cliquez sur le lien du message reçu.
2. **Installez un viewer** : [Firestorm](https://www.firestormviewer.org/) est le plus utilisé.
3. **Ajoutez la grille** dans le viewer (Préférences > OpenSim > Gestionnaire de grilles) avec l'adresse de connexion ci-dessous, puis choisissez-la sur l'écran de connexion.
4. **Connectez-vous** avec le nom de votre avatar et votre mot de passe.
