# Pour commencer

1. [w4os-register]**Créez votre avatar** sur la [page d'inscription](/register) : choisissez son nom, sa première tenue et un mot de passe, puis cliquez sur le lien du message reçu.[/w4os-register]
1. **Installez un viewer** : [Firestorm](https://www.firestormviewer.org/) est le plus utilisé.
1. **Ajoutez la grille** dans le viewer (Préférences > OpenSim > Gestionnaire de grilles) avec son URI de connexion : [login-uri]
1. **Connectez-vous** avec le nom de votre avatar et votre mot de passe.

Mot de passe perdu ? [En choisir un nouveau](/forgot_password).
