# Per iniziare

1. **Crea il tuo avatar** nella [pagina di registrazione](/register): scegli il suo nome, il primo outfit e una password, poi clicca sul link dell'email che ricevi.
2. **Installa un viewer**: [Firestorm](https://www.firestormviewer.org/) è il più usato.
3. **Aggiungi la griglia** nel viewer (Preferenze > OpenSim > Gestione griglie) con il suo URI di accesso: [w4os info="uri" /]
4. **Accedi** con il nome del tuo avatar e la tua password.

Password dimenticata? [Scegline una nuova](/forgot_password).
