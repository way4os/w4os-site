# Erste Schritte

1. **Erstelle deinen Avatar** auf der [Registrierungsseite](/register): Wähle seinen Namen, sein erstes Outfit und ein Passwort, dann klicke auf den Link in der E-Mail, die du erhältst.
2. **Installiere einen Viewer**: [Firestorm](https://www.firestormviewer.org/) ist der meistgenutzte.
3. **Füge das Grid** im Viewer hinzu (Einstellungen > OpenSim > Grid-Manager) mit seiner Login-URI: [w4os info="uri" /]
4. **Melde dich an** mit dem Namen deines Avatars und deinem Passwort.

Passwort vergessen? [Wähle ein neues](/forgot_password).
